저장한 파일을 GitHub에 반영하기

companies.csv가 다운로드 폴더에 저장되었습니다.

  1. 저장소에서 config → companies.csv 를 엽니다
  2. 연필 아이콘(Edit this file)을 누릅니다
  3. 기존 내용을 전체 선택 후 삭제합니다 (Ctrl+A → Delete)
  4. 아래 클립보드에 복사를 누른 뒤 붙여넣습니다 (Ctrl+V)
  5. Commit changes 를 누릅니다
